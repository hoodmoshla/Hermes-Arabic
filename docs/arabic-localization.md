# التعريب العربي في Hermes

تعالج ملفات المشروع اللغة في نقاطها الفعلية، بدل الاكتفاء بتغيير نصوص محدودة بعد عرضها:

- `android/app/src/main/python/hermes_cli/web_dist/locales/ar.json` هو قاموس واجهة Hermes React الأصلية، ويطابق بنية مفاتيح locale الإنجليزية. ويُحمّل التطبيق العربية و`dir="rtl"` افتراضيًا.
- `android/app/src/main/python/locales/ar.yaml` يعرّب رسائل Hermes النظامية الثابتة، ويطابق مفاتيح ومتغيرات `en.yaml`.
- `www/locales/ar-mobile.json` قاموس منظّم للواجهة المحمولة. مفاتيحه الصينية/الإنجليزية هي نصوص مصدر تُستخدم للعثور على عناصر واجهة Hermes القديمة؛ القيم العربية هي التي تظهر للمستخدم. تُستخدم النسخة نفسها من الجذر المحلي في Android ولوحة Hermes.
- `www/hermes-arabic-mobile.css` يضبط الاتجاه والتخطيط والألوان والتباين في الشاشة الضيقة، مع قواعد مستقلة للوضع الداكن وحقول الروابط والرموز البرمجية.

## ما يبقى دون ترجمة

لا تُترجم رسائل المستخدم أو ردود النموذج أو أسماء النماذج والمستودعات والفروع وسير العمل أو عناوين API والروابط والمسارات والأوامر ومحتوى الملفات. هذه بيانات أو معرّفات وليست نصوص واجهة. ولا يطبّق محرك التعريب ترجمة على سجل المحادثة أو مخرجات الطرفية أو مناطق `code` و`pre` وحقول الإدخال. الأسماء التقنية والمنصات التي تظهر للمستخدم — مثل GitHub وAPI وOAuth وMCP وADB وأسماء المزوّدين والصلاحيات الحرفية — موثقة مع سبب الاحتفاظ بها في `android/app/src/main/python/locales/ui-technical-terms.json`.

توجد كلمات صينية في بعض التعابير النمطية فقط للتعرّف على حالات قديمة من Hermes أو تسميات لوحة المفاتيح الأصلية؛ لا تُعرض هذه التعابير للمستخدم. كما تبقى تسمية اللغة الصينية في اختيار اللغة عند تحديدها صراحةً؛ أما أول تشغيل فيبدأ بالعربية، ويمكن للمستخدم تغيير اللغة من الإعدادات.

مفاتيح المصدر غير العربية في `ar-mobile.json` ليست نصوصًا مرئية؛ هي مفاتيح مطابقة فقط، ويشترط الاختبار أن تكون القيم عربية وألا تبقى عبارة صينية بلا قيمة عربية. وتوجد اختبارات خاصة لعبارة الصفحة الرئيسية، وإعداد النموذج، وسير العمل، والخصوصية، وأزرار الملفات والكاميرا والإملاء الصوتي.

## التحقق

شغّل:

```bash
python3 scripts/verify_project.py
python3 -m unittest discover -s tests -v
cd android && ./gradlew :app:testDebugUnitTest :app:assembleRelease
```

التحقق الآلي من واجهة الهاتف لا يغني عن اختبارها على جهاز Samsung فعلي؛ يجب التصريح بذلك عند عدم توفر الجهاز. كذلك لا تُعد نتائج عرض المقاسات المحاكية إثباتًا لاختبار جهاز حقيقي.
